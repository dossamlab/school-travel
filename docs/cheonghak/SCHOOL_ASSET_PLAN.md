# 학교 탐방 Blender 모형 개선

사용자 승인 범위: 본관 외관 → 정문·중앙현관 → 실내 가구 순서로 제작하고 학교 탐방 견본에 연결한다.

## 공통 기준

- `school-tour`에서 작업하며 기존 방탈출 게임의 배포 주소와 main은 변경하지 않는다.
- 청학고등학교의 확인된 외관을 참고해 따뜻한 벽돌, 밝은 창틀, 낮은 회색 지붕을 표현한다. 아이보리·민트·목재의 기존 그림체와 조화를 맞춘다.
- 사진은 형태 참고용이다. 지도 이미지나 외부 사진을 배포 모형에 넣지 않는다.
- 형태·상대 위치는 PDF, 현재 방 이름은 웹 안내도, 1층 창고는 사용자의 현장 설명을 따른다. `school-plan-data.ts`와 `SCHOOL_PLAN_MAPPING.md`를 기준으로 하며, 웹 변환 격자를 물리적 형태로 사용하지 않는다. 치수는 실측 복원이 아니다.
- 길찾기, 문틈, 가구 충돌 범위와 이동 조작을 유지한다. 장식으로 통로를 막지 않는다.
- 원본 제작 스크립트와 내보낸 GLB를 함께 보존한다. Blender로 로컬 제작하며 새 유료 서비스는 사용하지 않는다.
- 새 학교 모형 합계 6 MiB(약 6.29 MB) 미만을 목표로 한다. 실제 휴대기기 성능은 별도 측정이 필요하다.

## 순서와 검증

1. 본관: 반복 창호·외벽 마감·지붕 디테일 제작 → 기존 건물 윤곽과 층 높이, 확대 화면에서 확인.
2. 출입구: 정문·중앙현관·실내 문 마감 제작 → 경첩 회전, 선택, 통과, 실내 전환 확인.
3. 가구: 책상·책장·벤치 제작 → 기존 배치 안에 들어가는지, 바닥 접지와 길찾기 확인.
4. 통합: 자료 출처와 제작 명령 기록 → 타입 검사·전체 테스트·배포용 빌드, 데스크톱·휴대폰 크기 브라우저 점검.

## 진행 기록

- 제작 전: 기존 구조 견본의 이동 및 문 조작을 보존하는 방식으로 개선을 시작함.
- 완료: 본관·출입구·가구를 연결하고 전체 검사 62개, 타입 검사·빌드, 데스크톱·휴대폰 크기 화면을 확인함. 상세 수치와 한계는 `SCHOOL_TOUR_VERIFICATION.md`에 기록함.
