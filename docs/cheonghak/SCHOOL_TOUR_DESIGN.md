# 학교 탐방 견본 설계

## 2026-10-15 치수 적용 기준

외부 보행 기준은 사용자 후속 사진에 따라 교문에서 농구장까지 완만하게 낮아지는 지면으로 보정한다. 급식동 서쪽에는 약 10단 외부 출입 계단과 유리문을 두고 북쪽 복도와 이어지는 식당 통행 공간을 제공한다. 외부 표고·문 위치·급식실 가구 및 조리 구역 경계는 실측/실내 사진 확인 전의 추정이며 `SCHOOL_TOUR_VERIFICATION.md`에 근거와 검증을 기록한다. 캐릭터를 가리는 벽은 시선 검사로 일시 투명화하되 물리적인 통과 제한은 유지한다.

추가된 `교사동 도면(청학고).pdf`의 A-202가 1층 길이·배치 기준을 대체한다. 구조 폭 81m, 깊이 55.8m, 주복도 2.7m, 남쪽 실 깊이 7.5m와 동편 열의 4.5m 후퇴를 적용하고 캐릭터 키를 1.70m로 맞춘다. 현재 실명과 영상의 연결 관계는 유지하되 세부 칸막이·문·가구 치수는 추정이다. 1층 바닥·이동·안내도는 같은 좌표를 쓰고, 2–5층 안내도와 기존 Blender 외관은 종전 개략 데이터로 남긴다. 아래 자료 이력보다 이 기준이 우선하며 상세 근거는 `SCHOOL_METRIC_PLAN.md`를 따른다.

2026-10-14 · 첫 제작 범위: 학교 전체 배치 + 주요 건물 1층

## 목적과 작업 범위

처음 학교를 방문한 사람이 캐릭터를 직접 움직이며 건물의 위치를 익히고, 주요 건물 1층의 방문 목적지까지 찾아갈 수 있는 웹 탐방 도구를 만든다. 사용자가 선택한 첫 범위는 학교 전체 배치와 주요 건물 1층이다.

작업 브랜치는 `school-tour`이며, 시작 기준은 기존 방탈출 게임의 `61d0f35` 커밋이다. 학교용 화면과 자료는 이 브랜치에서 개발한다. 현재 연결된 게임 운영 주소에 학교 견본을 덮어 배포하지 않는다. 학교용 공개 배포는 배치도에 따른 견본 검토 후 배포 대상을 정한다.

## 견본에서 제공할 경험

| 구성 | 동작 |
| --- | --- |
| 학교 전체 보기 | 배치도에 있는 정문·건물·운동장과 주요 보행 통로를 표시한다. |
| 직접 이동 | PC의 WASD·바닥 클릭과 모바일 화면 이동판으로 걷는다. 시점은 캐릭터를 따라온다. |
| 실내 탐방 | 주요 건물 출입구를 통해 1층 장면으로 이동하고, 다시 야외로 나올 수 있다. |
| 장소 안내 | 가까이 간 장소의 이름과 조작 안내를 표시하고, 클릭·터치·Space로 설명을 연다. |
| 공간 살펴보기 | 안내할 공간의 문을 열고 내부를 살펴본다. 실제 사진이 제공되면 설명과 함께 볼 수 있다. |
| 목적지 찾기 | 배치도에서 확인한 방문 목적지를 선택하면 현재 위치에서 이어지는 보행 경로를 표시한다. |

다른 층의 위치는 전체 안내에 포함할 수 있지만, 첫 견본에서 직접 걸어 다니는 실내 범위는 주요 건물 1층이다. 1층의 구체적인 방문 목적지와 공개할 공간은 제공받은 안내 자료를 기준으로 구성한다.

## 그림체와 공간 표현

- 기존 게임의 아이보리·민트·나무색, 둥근 모서리, 부드러운 조명과 캐릭터 비율을 활용한다.
- 건물과 실내 장식은 그림체에 맞게 단순화하되 건물의 상대 위치, 통로 연결, 출입문과 계단 위치는 배치도에 맞춘다.
- 실내에서는 카메라 쪽 벽을 낮추거나 가려 캐릭터와 통로를 볼 수 있게 한다.
- 야외와 1층은 필요한 장면을 나누어 표시한다. 모바일에서 작은 안내문을 읽거나 복잡한 조작을 반복하지 않도록 구성한다.
- 캐릭터·가구 등 현재 보유한 모형을 먼저 활용한다. 별도 유료 에셋 생성은 이번 준비 작업에 포함하지 않는다.

## 구현 구성

- 기존 `src/player.ts`의 모형 로딩·걷기 표현과 현재 이동·시점·근접 안내 동작을 재사용할 수 있는 부분부터 확인한다.
- 학교 배치와 장소 설명은 학교 전용 데이터로 관리한다. 학교용 화면은 방탈출 퍼즐의 완료 상태에 의존하지 않도록 구성한다.
- 이동 가능한 영역과 장소 사이의 연결 관계를 같은 배치 자료에서 정의해, 직접 걷기와 길 안내의 경로가 일치하도록 한다.
- 장소 안내창을 닫은 뒤에도 이동 키가 동작하고, 지도나 안내창을 조작할 때 캐릭터가 함께 움직이지 않도록 한다.

## 제작에 필요한 입력 자료

1. **학교 전체 배치도:** 건물 이름, 정문, 운동장, 건물 사이의 통로와 출입구가 보이는 이미지 또는 PDF.
2. **주요 건물 1층 배치도:** 공간 이름, 복도, 출입문, 계단 위치가 보이는 이미지 또는 PDF. 주요 건물 이름을 함께 알려 준다.
3. **선택 자료:** 건물 정면·복도·대표 공간 사진과 방문자에게 보여 줄 짧은 설명.

2026-10-14에 제공된 `배치도(면적, 최종).pdf`는 2023학년도 1~5층의 공간 형태·상대 위치 기준이다. 현재 실 명칭은 사용자가 지정한 https://dasancamp.netlify.app/ 를 기준으로 한다. 웹 안내도는 변환 중 모양이 달라졌으므로 물리적 배치 기준으로 사용하지 않는다. 1층 창고는 사용자의 현장 설명에 따라 여자화장실 옆에 두고 도서관 앞은 연속 복도로 보존한다.

`src/school-floor-data.ts`는 웹 실명 대조용 원본이고, `src/school-plan-data.ts`는 PDF를 옮긴 공간 데이터다. 3D 공간·이동·층별 지도·Blender 외관이 같은 공간 데이터를 사용한다. 대응 내역과 미확인 구획은 `SCHOOL_PLAN_MAPPING.md`에 기록한다. 과거 면적은 출처와 함께 참고값으로 표시하며 현행 실측 면적으로 단정하지 않는다. 출입문 위치·높이·가구·길이는 견본용 추정이다.

외관은 네이버 위성지도·거리뷰와 학교 공식 시설 사진을 추가로 확인했다. 본관 앞 운동장, 남측 빨강·파랑 코트, 동쪽 도로와 정문 진입부, 벽돌 외벽·밝은 층띠·측벽 다이아몬드 장식을 단순화해 반영한다. 야외에서는 좁은 지정 경로에 한정하지 않고 현재 모델의 교내 지면 중 건물·벽·기둥·차량·소품이 차지하지 않은 공간을 걷는다. 교문 옆길·필로티 사이의 빈 공간·매점·분리수거장·텃밭 주변·서쪽 건물 옆길을 연결하고, 북측 출입문으로 급식실 입구와 농구장 계단까지 이어진다. 본관 앞 구령대 양옆과 서쪽 계단으로 운동장까지 내려갈 수 있다. 높이 차이가 있는 곳은 계단을 이용한다. ‘동편·뒤뜰 보기’는 제거하고 외부에서 본관 뒤쪽으로 접근하면 걷는 위치에 맞춰 건물을 단면으로 보여 준다. 2~5층의 현재 실 배치는 층별 지도에서 열람하고, 직접 탐방하는 실내는 1층에 한정한다.

2026-10-15 현장 영상과 사용자 주석 사진을 추가 반영했다. 1층은 동편출입구→도서관→열린도서관→중앙로비의 연결, 복도 반대편 반납함·엘리베이터홀, 북쪽통로 왼쪽 급식실을 표시한다. 외관은 청록색 매점 아래의 열린 필로티, 바깥 분리수거장·텃밭, 학교보안관실과 동편출입구를 구분하고 ‘동편·뒤뜰 보기’로 확인할 수 있다. 농구장 방향은 유지한다. 정확한 길이와 홀·급식실 내부 경계는 미확인으로 남기며 원본 영상·캡처는 배포하지 않는다. 자세한 근거는 `SCHOOL_VIDEO_REFINEMENT.md`를 따른다.

## 제작 순서와 확인 기준

| 단계 | 결과 | 확인 방법 |
| --- | --- | --- |
| 배치 확인 | 야외와 1층의 공간·통로 연결 목록 | 제공된 배치도와 대조해 건물 이름·문·복도 연결을 확인한다. |
| 이동 견본 | 정문에서 주요 건물 1층까지 이어지는 이동 | 벽을 통과하지 않고 출입구로 왕복하며, 실내외 이동 때 캐릭터가 문이나 벽 안에 생기지 않는지 확인한다. |
| 안내 연결 | 장소 설명과 목적지 경로 표시 | 가까운 장소에만 표식이 나타나고, 길 안내가 실제 걸을 수 있는 통로를 따르는지 확인한다. |
| 외형·조작 점검 | 기존 그림체와 어울리는 학교 견본 | PC 키보드·클릭, 모바일 화면 이동, 안내창 닫기 이후 이동, 화면 크기별 글자·버튼을 점검한다. |

코드 구현 후 기존 프로젝트의 타입 검사·테스트·빌드를 실행하고, 학교의 실내외 이동과 안내 경로를 화면에서 확인한다. 모바일 성능은 대표 실기기에서 확인하며, 측정 전에는 성능 목표를 달성한 것으로 기록하지 않는다.

## 로컬 검토와 원본 보관

2026-10-15 사용자 요청에 따라 2~5층 실내 확장 전에 1층 북편 필로티 경계를 우선 보정했다. 북편 주차장 연결 바닥은 회색이며 실내 줄눈을 표시하지 않는다. 북편 계단 외부 세 면은 반투명 벽으로 닫고 복도 쪽 진입을 유지한다. 위성사진의 상대 관계에 맞춰 교외 북측·동측 도로와 둘레 울타리를 근사 배치했으며, 정문 이외의 울타리는 통과할 수 없다. 울타리 안의 주차장·매점·분리수거장·급식실 입구·농구장과 운동장 주변 보행 공간은 문·계단을 통해 연결한다. 남쪽 코트도 운동장 높이에서 걸을 수 있다. 게임 화면의 휠은 확대·축소를 지원한다. 울타리 실측·도로 곡선의 정밀 재현은 미완료다.

- 개발 중에는 `npm run dev -- --host 127.0.0.1 --port 5186 --strictPort`로 이 PC의 미리보기를 연다.
- 검토용 완성 화면은 `npm run build` 후 `npm run preview -- --host 127.0.0.1 --port 5186 --strictPort`로 빌드 결과만 제공한다.
- 원본 대화·면적 PDF는 작업 폴더에 보존하되 Git과 개발 서버 제공 대상에서 제외한다. `vite.config.ts`는 Vite의 기본 비밀 파일 차단도 함께 유지한다.
- 새 학교용 에셋을 구매하거나 서비스를 연결하지 않았다. 기존 자산의 출처 표시는 화면 도움말과 기존 에셋 문서를 따른다.
