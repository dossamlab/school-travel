# 3분 학교 투어

시작 화면의 `3분 추천 코스 둘러보기`, 탐방 화면 오른쪽의 `3분 투어`에서 선택한다. 코스를 시작하면 교문으로 이동한다. 약 3분은 이동과 설명 읽기를 포함한 안내 시간이며 제한 시간은 없다.

- 신입생: 교문 출발 → 중앙현관 → 열린도서관 → 도서관 → 급식실 → 북편 주차장 출입문을 거쳐 매점 → 중앙계단.
- 학부모: 교문 출발 → 중앙현관 → 행정실 → 교장실 → 도서관 → 중앙로비.
- 송천홀(시청각실) 찾아가기: 교문 출발 → 중앙현관 → 북편 계단 → 자동으로 2층 이동 → 송천홀 입구.

도착하면 설명이 열리고 다음 버튼으로 이어간다. 중앙현관은 기존 출입 상호작용으로 실내에 들어간다. 주차장 출입문이 닫혔으면 문 앞에서 열기 버튼을 누르면 안내가 이어진다. 수동 이동은 평지 자동 걷기만 중단하며 코스 진행 순서는 남는다. 둘러본 뒤 코스 버튼에서 계속할 수 있다. 마지막 장소에서는 완료 화면과 방명록 연결을 제공한다. 진행 정보는 현재 탐방 중에만 유지하며 새로고침하면 초기화한다.

서편·북편·중앙·동편 계단 앞에서 인접 층으로 이동하는 버튼이 나타난다. 1층은 올라가기, 2~4층은 내려가기와 올라가기, 5층은 내려가기만 제공한다. 실제 계단의 두 구간과 중간 계단참을 따라 기존 충돌·높이 계산으로 이동하며 순간이동하지 않는다. 자동 이동 중 이동키·바닥 클릭은 잠시 제한하고, 창을 열거나 브라우저가 숨겨지면 이동을 일시 정지한다. 층 복도 도착 후 다시 직접 조작할 수 있다.

2026-10-16 검증: 전체 자동 검사 116개, 타입 검사, 빌드 통과. 두 코스의 모든 구간을 닫힌 문 상태에서 충돌 검사와 함께 완주하는 테스트를 추가했다. 브라우저에서 두 코스 완주, 중앙현관 진입, 수동 이동으로 중단 후 재개, 설명 다시 열기, 코스 종료, 완료 후 방명록 열기를 확인했다. 390×844 및 320×568 화면의 코스 선택창에서 가로 넘침이 없었다. 실제 휴대기기 성능 측정은 아니다. 기존 큰 스크립트 묶음 경고는 남아 있다.

같은 날 추가 변경: 전체 검사 123개 통과 후, 브라우저에서 발견한 소수점 이동 잔여량 문제를 재현 검사에 추가하고 관련 14개 검사·타입 검사·빌드를 다시 통과했다. 매점 방문과 실내 복귀를 포함한 신입생 코스, 북편 계단 자동 상승과 송천홀 도착, 2층 버튼 두 개 표시 및 1층 자동 하강을 실제 UI로 확인했다. 계단은 네 곳 모두 1~5층 왕복을 서로 다른 프레임 이동량으로 검사한다.
