# 우리 학교로 바꾸기

청학 여행은 청학고등학교의 배치도·설계 도면·항공사진·로드뷰·실내 영상을 보고 만든 3D 학교 여행입니다. 이 안내서는 그 견본을 **선생님의 학교로 바꾸는 순서**를 설명합니다.

Claude Code나 Codex 같은 AI 코딩 도구를 쓰는 선생님을 위한 안내입니다. 코드를 직접 짜지 않아도 됩니다. 단계마다 **어느 파일을 고치는지**와 **AI에 붙여 넣을 요청문**을 함께 적었습니다. 한 번에 다 바꾸려 하지 말고, 단계마다 화면으로 확인하고 커밋하면서 나아가세요.

> 저장소의 `AGENTS.md`(Claude Code는 `CLAUDE.md`를 통해 같은 내용)를 AI가 자동으로 읽습니다. 개인정보·원본 자료·검사 규칙이 들어 있으니 지우지 마세요.

### 내 저장소 만들고 견본 실행하기

1. GitHub에서 이 저장소의 **Use this template → Create a new repository**를 누릅니다. 포크(Fork)보다 템플릿이 좋습니다. 선생님 학교의 기록이 깨끗하게 새로 시작됩니다.
2. 내 PC로 내려받아 실행합니다.

```bash
git clone https://github.com/<내 계정>/<내 저장소>.git
```

```bash
npm ci
```

```bash
npm run dev
```

터미널에 나온 `Local` 주소를 열어 **청학고 견본이 그대로 걸어지는지** 먼저 확인합니다. 여기서 막히면 그다음 단계도 확인할 수 없습니다.

**지켜 주세요**

- 도면·배치도는 학교 내부 자료일 수 있습니다. 사이트에는 **숫자와 실 이름만** 옮기고, 원본 파일·이미지는 저장소에 올리지 않습니다. 공개해도 되는지는 학교와 먼저 확인하세요.

### 좌표 약속 — AI가 꼭 알아야 하는 것

- 단위는 **미터**입니다. 사이트 안에서 x는 동서(동쪽이 +), z는 남북(남쪽이 +)입니다. 1층 남쪽 전면이 z=20.25에 오도록 맞춰져 있습니다.
- 층별 배치는 격자 칸(`col` 1~43, `row` 1~10)으로 적고, `school-layout.ts`의 `cellRect()`가 미터로 바꿉니다. 1층은 도면 치수(`firstFloorDimensions`)를, 2층 이상은 배치도의 가로세로 비율(`planAspectRatios`)을 씁니다.
- 걷기·문·가구 충돌·길 안내·미니맵·외관 모형이 **같은 배치 자료를 공유**합니다. 한 곳만 고치면 벽을 뚫고 걷거나 문이 엉뚱한 곳에 생깁니다.
- 청학고에서 이 약속을 어떻게 정했는지는 [청학고 제작 기록](cheonghak/SCHOOL_PLAN_MAPPING.md)과 [치수 기록](cheonghak/SCHOOL_METRIC_PLAN.md)에 있습니다. AI에게 함께 읽히면 같은 방식으로 작업합니다.

## 1. 이름과 주소 바꾸기

`src/school-config.ts` 하나만 고치면 화면 위쪽 이름, 첫 화면, 도움말의 자료 출처, 로비 현수막, 기념사진 글씨, 브라우저 제목, 카카오톡 공유 미리보기, 홈 화면 아이콘 이름이 함께 바뀝니다.

> **AI 요청문**
>
> `src/school-config.ts`를 우리 학교로 바꿔 줘. 학교 이름은 ○○고등학교, 짧은 이름은 ○○, 사이트 이름은 "○○ 여행"이야. 사이트 주소는 아직 없으니 `https://<저장소 이름>.vercel.app/`로 두고, 시트 주소(`dataUrl`)는 비워 둬. 도움말 `about`의 설명·링크·제작자는 우리 학교 자료(references 폴더)에 맞게 다시 쓰고, 청학고 이야기는 남기지 마. 단, `src/template-credit.ts`의 견본 제작자 표시(Template by 청학고 도쌤)는 출처 표시라 그대로 둬. 끝나면 `npm test`와 `npm run build`를 실행해 줘.

첫 화면 아래와 도움말 끝의 `Template by 청학고 도쌤`은 견본을 만든 사람 표시입니다(`src/template-credit.ts`). 학교 이름과 달리 바꾸지 않고 남겨 둡니다. 우리 학교 쪽 제작자는 `about.maker`에 적습니다.

공유 이미지(`public/school-share-v1.jpg`, 1200×630)는 학교 모형이 완성된 뒤 바꿉니다. `assets/school-share-card.html`을 개발 서버에서 열고 같은 크기로 화면을 찍으면 됩니다.

**확인:** 첫 화면과 위쪽 이름, 브라우저 탭 제목이 바뀌었는지 봅니다.

## 2. 층별 배치 옮기기

가장 중요한 단계입니다. 배치도의 각 실을 격자 칸으로 옮깁니다.

- `src/school-plan-data.ts`의 `schematicPlanFloorData`: 층마다 `{name, col, colSpan, row, rowSpan, border}` 목록. `name`이 빈 칸은 이름 없는 구획, `\n`은 안내도에서 줄을 바꾸는 자리입니다.
- `schematicPlanAspectRatios`: 배치도에서 각 층 그림의 **높이÷너비**. 가로세로 배율을 같게 유지합니다.
- `firstFloorDimensions`와 `planFloorData[1]`: 1층은 설계 도면의 미터 치수로 다시 적습니다. 도면이 없으면 배치도 비율만으로 시작하고, 나중에 치수를 넣어도 됩니다.
- `src/school-floor-data.ts`: 청학고가 실 이름을 처음 읽어 온 원본입니다. 새 학교는 이 파일을 지우지 말고 `school-plan-data.ts`를 정본으로 씁니다.

> **AI 요청문**
>
> `references/배치도.pdf`를 보고 1~○층 배치를 `src/school-plan-data.ts`의 `schematicPlanFloorData`와 `schematicPlanAspectRatios`로 옮겨 줘. `docs/cheonghak/SCHOOL_PLAN_MAPPING.md`에 적힌 정규화 방법(외곽 픽셀 → col 1~43, row 1~10, 공유 벽은 같은 경계값)을 그대로 따라. 이름을 확신할 수 없는 구획은 비워 두고 목록으로 알려 줘. 옮긴 근거와 추정한 부분은 `docs/우리학교/배치-대응.md`에 표로 남겨 줘.

> **AI 요청문 (1층 치수)**
>
> `references/도면-1층.pdf`의 기준선 치수로 `firstFloorDimensions`와 `planFloorData[1]`을 다시 계산해 줘. 복도 폭과 교실 깊이를 도면대로 쓰고, 문 위치·벽 두께처럼 도면에 없는 값은 추정이라고 기록해 줘. `docs/cheonghak/SCHOOL_METRIC_PLAN.md`의 방식을 참고해.

**확인:** 사이트의 `교실 바로가기`(층별 안내도)에서 각 층 실 배치가 배치도와 같은지 봅니다.

## 3. 1층 문·계단·현관·교문

- `src/school-structure.ts`: 계단(`stairs`, 층마다 이어지는 4곳), 층 높이(`floorRise`), 출입구와 경사로, 문(`portals`), 바깥 벽(`boundaryWalls`), 급식실·농구장처럼 높이가 다른 바닥.
- `src/school-layout.ts`: 장소 목록(`places`) — 1층 배치에서 자동으로 만들어지고, 문 방향·들어갈 수 있는 방·설명을 덧붙입니다. 교문 위치(`campusGate`), 출발 위치(`gateSpawn`, `floorSpawn`), 1층 교직원 위치(`schoolResidents`)도 여기 있습니다.

> **AI 요청문**
>
> 새 1층 배치에 맞춰 `src/school-structure.ts`의 계단·문·출입구와 `src/school-layout.ts`의 교문·출발 위치를 고쳐 줘. 계단은 `references/메모.md`에 적은 4곳이야. 모든 장소의 입구까지 걸어갈 수 있어야 하고, 닫힌 문은 지나갈 수 없어야 해. 청학고에만 맞는 특수 구조(필로티 주차장, 농구장 계단, 급식실 출입구)는 우리 학교에 없으면 빼 줘.

**확인:** 교문에서 출발해 현관으로 들어가고, 1층의 모든 문을 열어 들어가 봅니다. 계단으로 2층에 올라가 봅니다.

## 4. 운동장·주차장·울타리

`src/school-outdoors.ts`에 운동장(`fieldRect`), 운동장 높이 차(`fieldDrop`), 계단과 경사로, 학교 경계(`campusOutline`, 울타리), 주차된 차, 텃밭, 분리수거장이 있습니다. 항공사진에서 건물 크기를 기준으로 거리를 잽니다.

> **AI 요청문**
>
> `references/항공사진.png`에서 1층 건물 외곽(가로 ○○m)을 기준 길이로 삼아 운동장·주차장·교문·울타리 위치를 미터로 재고, `src/school-outdoors.ts`를 고쳐 줘. 잰 방법과 오차가 클 만한 곳을 알려 줘.

## 5. 2층 이상

`src/school-upper-floors.ts`가 2층 이상의 교실·특별실·화장실·복도를 배치 자료에서 만듭니다. 교실의 문 방향, 특별실 종류(`style`: 일반교실·교무실·실험실·강당·체육관…), 직접 가구를 놓은 방(`customRooms`)을 정합니다.

> **AI 요청문**
>
> 새 배치에 맞춰 `src/school-upper-floors.ts`를 고쳐 줘. 실 이름으로 방 종류(`style`)를 정하고, 모든 방의 문이 복도 쪽을 보게 해 줘. 2~○층의 모든 방 입구까지 계단에서 걸어갈 수 있어야 해.

## 6. 특별실 가구와 눌러 보는 물건

- `src/school-classrooms.ts`: 방마다 가구 배치(`classroomLayout`)와 눌러 보는 물건(`props`: 3D 프린터, 현미경, 게임기, 운동기구, 포토존…).
- `assets/build_school_classrooms.py`: 가구 모형. 새 가구를 만들면 `classroomModels`의 크기와 모형 크기가 같아야 합니다(검사가 확인합니다).

실내 사진·영상이 있는 방부터 바꾸고, 나머지 방은 기본 견본 가구로 둡니다.

> **AI 요청문**
>
> `references/교실/물리실.mp4`를 보고 2층 물리실 가구를 `src/school-classrooms.ts`에 배치해 줘. 기존 가구 모형을 먼저 쓰고, 꼭 필요한 새 가구만 `assets/build_school_classrooms.py`에 추가해. 가구가 문을 막거나 벽 밖으로 나가면 안 돼.

## 7. 건물 외관·현관·가구 모형

배치(2~4단계)를 바꾼 뒤 Blender 스크립트로 모형을 다시 만듭니다. 외벽 색·창 모양·현관 차양·교문은 로드뷰를 보고 `assets/build_school.py`에서 바꿉니다. 자세한 명령과 모형 이름 약속은 [3D 모형 만들기](3D-모형-만들기.md)에 있습니다.

> **AI 요청문**
>

## 검사 다루기 — 청학고 검사를 우리 학교 검사로

`tests/` 폴더의 검사는 두 종류입니다.

- **어느 학교에나 맞는 검사**: 모든 장소의 입구까지 걸어갈 수 있다, 닫힌 문은 막는다, 가구가 벽 밖으로 나가지 않는다, 모형 크기 예산, 설정 파일 형식. 그대로 두고 통과시킵니다.
- **청학고에만 맞는 검사**: "송천홀 코스", "A-202 북쪽 출입구", "도서관 앞 복도는 창고가 아니다"처럼 청학고 사실을 확인합니다. 배치를 바꾸면 실패하는 것이 정상입니다.

실패한 검사를 그냥 지우지 마세요. AI에게 **우리 학교의 같은 사실로 바꾸게** 하면 다음 수정 때 실수를 막아 줍니다.

> **AI 요청문**
>
> `npm test`에서 실패한 검사를 하나씩 보고, 청학고에만 맞는 사실을 확인하는 검사는 우리 학교의 같은 종류 사실로 바꿔 줘. 어느 학교에나 맞는 검사(걸어서 닿기, 문 막기, 가구 위치, 모형 예산)는 코드를 고쳐서 통과시키고, 검사를 약하게 만들지 마.
