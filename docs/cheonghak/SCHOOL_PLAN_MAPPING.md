# 도면 형태와 현재 실명 대응

## 기준과 한계

- 1층 치수 기준: **교사동 도면(청학고).pdf 2쪽 A-202**. 2–5층 안내도와 기존 외관 모형은 **2023학년도 교실 배치도 PDF**의 개략 형태를 유지한다.
- 현재 실명 기준: `src/school-floor-data.ts`에 보존된 공개 학교 안내도의 명칭. 공개 출처는 [다산캠프](https://dasancamp.netlify.app/)이며, 이 문서는 공개 명칭의 현장 확인을 뜻하지 않는다.
- 사용자 직접 확인이 우선하는 예외: **1층 창고는 여자 화장실 옆이며, 도서관 앞 복도의 북쪽에 있다.**
- 기존 2023학년도 배치도는 안내도이며, 새 교사동 건축 도면에는 길이 치수가 있다. 1층은 확인된 치수를 적용하되 문 위치·벽 두께·현재 내부 분할은 미확인으로 구분한다.
- 비공개 PDF와 그 이미지 파일은 저장소·웹 배포물에 넣지 않는다. 이 문서는 대응 설명과 정규화된 수치만 보존한다.
- 원래 공개 안내도의 격자 위치는 현재 명칭을 확인하는 용도로만 사용한다. 도면과 다른 날개 배치·복도 단절은 그대로 복제하지 않는다.
- 도면의 빈 영역은 별도 현장 근거 없이 현재 실명으로 채우지 않는다. 2026-10-15 사용자가 제공한 영상·주석 사진으로 확인된 1층 급식실·필로티·엘리베이터홀은 아래 예외를 적용한다.

## 기존 개략 좌표 계약 — 2–5층·외관용

다음은 기존 개략 모형의 기록이다. 현재 1층은 폭 81m·깊이 55.8m, x=계획좌표−40.5, z=계획좌표−35.55를 사용하며 주인공 키는 1.70m다.

이미지 미리보기의 약 1335×1888 좌표계에서 다음 외곽과 공유 경계를 읽었다. 이미지 확대 비율 자체가 길이 단위인 것은 아니다.

| 층 | 미리보기 외곽 x | 미리보기 외곽 y |
|---|---|---|
| 1 | 151~1183 | 1582~1842 |
| 2 | 150~1184 | 1161~1560 |
| 3 | 155~1179 | 771~1143 |
| 4 | 150~1184 | 500~759 |
| 5 | 151~1183 | 206~469 |

`col = 1 + (x-left)/(right-left) × 42`, `row = 1 + (y-top)/(bottom-top) × 9`로 각 층을 정규화한다. 도면의 위쪽은 row가 작은 쪽, 왼쪽은 col이 작은 쪽이다. 경계값을 소수점 4자리로 반올림한 후 두 경계의 차이로 span을 계산한다. 따라서 공유하는 벽은 같은 경계값을 사용하며, 계산 비교에는 부동소수점 오차를 고려한다.

데이터 범위는 col **1~43**, row **1~10**이다. 표시할 때는 `planAspectRatios`의 PDF 높이/너비 비율을 적용해 가로·세로에 같은 배율을 사용한다. 세계 좌표는 `x=(col-1)×1.875-39.375`, `z=(row-10)×78.75×planAspectRatios[floor]/9+20.25`이며 남측 전면을 맞춘다. 층별 안내도와 작은 위치 지도도 같은 종횡비를 쓴다. 이 수치는 게임 안의 크기이며 실측치가 아니다. 원본 층별 도식 자체의 경계 차이로 계단의 층간 x/z 위치가 완벽하게 일치하지 않으므로 향후 층 이동 시 목적층의 해당 계단 위치를 따로 찾아야 한다.

`src/school-plan-data.ts`는 2–5층의 현재 명칭 집합을 보존한다. 1층은 현장 확인에 따라 중앙현관→중앙로비, 동쪽 통로→동편출입구로 바꾸고 급식실·엘리베이터홀을 추가했다. 기존 텃밭 구획은 필로티 주차장이며 실제 텃밭은 건물 밖에 표시한다. 같은 이름의 구획 수는 도형 분할에 따라 달라질 수 있다. 외곽 안의 빈 부분 전체를 건물 바닥으로 채우는 자료가 아니다.

## 확인이 더 필요한 부분

1. 1층 창고의 존재·인접 관계는 사용자 확인 사항이며, **폭과 깊이는 근사**다.
2. 1층 지원실의 옛 두 칸 합병, 3층 라운지·4층 스터디존의 구획 합병은 현재 실명 수와 상대 순서에 맞춘 대응이다. 현재 벽 위치까지 확인한 자료는 없다.
3. 3층 비품창고와 4층 샤워실 두 곳의 내부 분할은 미확인이다. 특히 4층은 현장 확인 또는 최신 배치도 확보 후 우선 수정해야 한다.
4. 3~5층 남쪽 실명은 2023년 학급 번호를 현재 번호로 무작정 유지하지 않고, 현재 웹에 있는 왼쪽→오른쪽 순서를 도면의 9개 구획에 넣었다.
5. 4·5층 계단은 도면에서 확인되는 서쪽·중앙·동쪽 세 곳만 만들었다. 웹에서 중복 표시되던 계단 수를 근거 없이 물리 구획 수로 해석하지 않는다.
6. 문·출입 가능 방향·층간 수직 정렬은 이 자료만으로 확정할 수 없다. 직사각형 간 인접과 실제 출입문이 있다는 사실은 별개다.

## 2~5층 실내 산책의 치수 적용 (2026-10-15)

위의 실명 대응은 유지하되 실제 3D와 안내도의 형태는 `src/school-upper-floors.ts`의 건축 도면 미터 좌표를 공유한다. 전면 교실 9×7.5m, 복도 2.7m, 북쪽 통로 3m, 동쪽 날개 후퇴 4.5m를 적용했다. 현재 칸막이·출입문·가구는 견본이며 별도 현장 확인이 필요하다.

2층 송천홀은 새 건축 도면의 북서 확장부에 대응한다. 5층 송학관 관람석은 체육관 동쪽 가장자리의 세로 구획으로 보정했으며 체육관 상부 빈 공간을 바닥으로 채우지 않는다. 네 계단에서 2~5층 복도와 교실로 출입할 수 있고 층별 길 안내·문 조작·현재 위치 지도도 같은 좌표를 사용한다. 상세 치수와 추정 범위는 `SCHOOL_METRIC_PLAN.md`의 2~5층 항목을 따른다.
