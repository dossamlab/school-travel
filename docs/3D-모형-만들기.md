# 3D 모형 만들기 — Blender 스크립트

사이트는 `public/`의 GLB 파일(모형과 재질을 함께 담은 glTF 형식)을 읽기만 합니다. 모형은 `assets/`의 Blender 파이썬 스크립트가 만들기 때문에, 손으로 Blender를 만지지 않고 AI가 스크립트를 고친 뒤 다시 실행하면 됩니다. 참고 사진·지도·도면은 모형에 붙이지 않고 색·형태·치수만 참고합니다.

## 실행하는 법

Blender 5.2 이상이 필요합니다. 프로젝트 폴더에서 실행하며, `blender`가 명령 검색 경로에 없으면 설치 경로로 바꿉니다(Windows Git Bash 예: `"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"`). `--background`는 Blender 화면을 열지 않고 만든다는 뜻이고, `--python-exit-code 1`은 스크립트가 실패하면 명령도 실패로 끝나게 합니다.

```bash
blender --background --python-exit-code 1 --python assets/build_school.py
```

```bash
blender --background --python-exit-code 1 --python assets/build_school_classrooms.py
```

다시 만들면 `public/`의 파일을 덮어씁니다. 실행 전에 커밋해 두면 결과가 마음에 들지 않을 때 되돌릴 수 있습니다.

## 모형 목록

| 사이트 파일 | 만드는 스크립트 | 내용 |
| --- | --- | --- |
| `school-exterior.glb` | `build_school.py` (`-- exterior`) | 층별 배치에서 만든 본관 외곽, 외벽, 창틀·창턱, 지붕 |
| `school-entry.glb` | `build_school.py` (`-- entry`) | `entrance`: 중앙현관 차양 / `gate`: 교문 기둥·철문·울타리 |
| `school-furniture.glb` | `build_school.py` (`-- furniture`) | `door`: 경첩 문 / `desk`: 책상 / `shelf`: 책장 / `bench`: 벤치 |
| `school-classrooms.glb` | `build_school_classrooms.py` | 특별실·교실의 가구와 눌러 보는 물건 |
| `school-player-meshy.glb` | `prepare_player.py` 또는 `prepare_school_meshy.py` | 학생 캐릭터([학교 캐릭터 만들기](학교-캐릭터-만들기.md)) |
| `school-residents.glb` | `prepare_school_residents_meshy.py` | 교직원 캐릭터, 스탠딩 책상, 화장실 세면대·변기 |

`build_school.py` 끝에 `-- entry furniture`처럼 이름을 붙이면 그 모형만 다시 만들어 시간을 줄입니다.

## 지켜야 할 약속

- **이름**: 코드는 모형 안의 물체를 이름으로 찾습니다(`entrance`, `gate`, `door`, `desk`, `printer-cabinet-door-l`, `seat`…). 모양을 바꿔도 이름은 유지합니다.
- **단위와 방향**: 미터 단위입니다. 가구는 바닥(y=0)에 서고, 발자국 중심에 놓이고, +Z를 바라봅니다.
- **배치 공유**: 외관은 `src/school-plan-data.ts`의 같은 배치 자료로 만듭니다. 배치를 바꾸면 외관도 다시 만들어야 벽과 걷는 길이 맞습니다.
- **문**: 실내 문은 왼쪽 경첩이 원점이고 폭 1.74m, 높이 2.22m입니다. 사이트의 1.8m 문틈(`doorWidth`)과 맞아야 Space·클릭·통과가 일치합니다.
- **가구 크기**: `build_school_classrooms.py` 실행 로그의 `CLASSROOM_FOOTPRINTS`가 `src/school-classrooms.ts`의 `classroomModels` 크기와 같아야 합니다. `tests/school-classrooms.test.ts`가 확인합니다.
- **용량 예산**: 학교 외관·출입구·가구 세 파일 합계 6MiB 미만, 원본 삼각형 합계 20만 미만을 검사합니다. 휴대폰에서 부드럽게 돌아가기 위한 제작 예산이며, 실제 기기 속도를 보장하는 측정값은 아닙니다.

## 특별실의 움직이는 부분

| 이름 | 연결 |
| --- | --- |
| `printer-cabinet-door-l`, `printer-cabinet-door-r` | 3D 프린터 보관함 유리문 경첩. 열면 ∓1.9rad 회전 |
| `germ-incubator-a-door`, `germ-incubator-b-door` | 세균배양기 문 경첩. 안에서 `germ` 모형이 튀어나옵니다 |
| `power-rack-bar` | 스쿼트 랙의 바벨. 스쿼트하는 동안 캐릭터 목 높이를 따라 오르내립니다 |
| `seat` (여러 개) | 의자·벤치의 앉는 자리. 좌석 높이에 놓이고 +Z가 앉은 사람이 보는 방향입니다 |
| `arcade-*-screen`, `arcade-*-marquee`, `welcome-banner-face` | 게임기 화면·간판과 환영 현수막 글씨를 붙이는 자리. 글씨는 브라우저가 그리므로 한글 글꼴 파일이 필요 없습니다 |

## 다시 만든 뒤 확인

```bash
npm test
```

그다음 `npm run dev`로 확대한 화면에서 가구가 바닥에 붙어 있는지, 문을 열고 통과할 수 있는지, 가구 주변을 걸을 수 있는지 봅니다. 새 외부 모형을 가져왔다면 만든 사람·주소·이용 조건·바꾼 내용을 `ASSET_CREDITS.md`에 적습니다.
