# 청학고 제작 기록

예시 학교인 청학고등학교를 만들면서 남긴 설계·대응·검증 기록이다. 다른 학교를 만들 때 AI에게 "청학고 기록과 같은 방식으로"라고 하면 이 문서들을 참고해 작업한다. 청학고의 사실을 적은 기록이므로 다른 학교에서는 고치지 말고 `docs/우리학교/`에 새 기록을 쓴다.

| 문서 | 내용 |
| --- | --- |
| [SCHOOL_PLAN_MAPPING.md](SCHOOL_PLAN_MAPPING.md) | 배치도·도면의 각 실을 격자 칸(col·row)으로 옮긴 방법과 층별 대응표 |
| [SCHOOL_METRIC_PLAN.md](SCHOOL_METRIC_PLAN.md) | 1층 설계 도면의 치수를 미터로 적용한 기준과 추정한 부분 |
| [SCHOOL_VIDEO_REFINEMENT.md](SCHOOL_VIDEO_REFINEMENT.md) | 실내 영상으로 문·가구·특별실을 다듬은 기록 |
| [SCHOOL_UNIFORM_PLAN.md](SCHOOL_UNIFORM_PLAN.md) | 교복 주인공을 Meshy 원본에서 만든 과정 |
| [SCHOOL_GUIDED_TOURS.md](SCHOOL_GUIDED_TOURS.md) | 신입생·학부모 추천 코스 |
| [SCHOOL_TOUR_DESIGN.md](SCHOOL_TOUR_DESIGN.md), [SCHOOL_TOUR_PLAN.md](SCHOOL_TOUR_PLAN.md), [SCHOOL_ASSET_PLAN.md](SCHOOL_ASSET_PLAN.md) | 처음 탐방 사이트를 설계한 방향과 작업 계획 |
| [SCHOOL_TOUR_VERIFICATION.md](SCHOOL_TOUR_VERIFICATION.md) | 기능별 검증 기록 |

기록에 나오는 커밋 번호와 작업 가지는 공개 전 비공개 저장소의 것이라 이 저장소의 기록에는 없다. 청학 여행은 3D 방탈출 게임 견본의 캐릭터·소리·조작 코드에서 출발했으며, 공개하면서 방탈출 부분은 뺐다. 원본 도면·배치도·사진·영상은 저장소에 넣지 않았다.
