# 현장 영상 반영 계획과 근거

2026-10-15 제공된 내부·외관 영상과 사용자가 지정한 시점을 기존 PDF 기반 견본에 반영한다. 원본 영상과 추출 사진은 로컬 참고용이며 저장소·배포물에 넣지 않는다. 얼굴·차량번호·문서 내용·상표를 모형에 복제하지 않는다.

## 반영 순서

1. 동편출입구부터 중앙로비까지의 동선과 장소 경계를 맞춘다. PDF의 가로·세로 비율은 유지하고, 현장 확인된 명칭·연결을 우선한다. 농구장의 방향과 구획은 유지한다.
2. 도서관·열린도서관의 반복 유리벽과 금속 프레임, 연두색 도서 반납함, 엘리베이터홀, 로비 세로 목재 마감, 복도 바닥·벽 하부 마감과 게시판을 같은 그림체로 제작한다. 복도 중앙 통행과 문 개폐 공간을 비운다.
3. 외관의 밝은 황토 벽돌과 흰 층 띠, 동편출입구, 학교보안관실, 청록색 매점과 분리수거장, 기둥으로 열린 주차 공간·포장·식재를 보완한다. 확인되지 않은 운동장 계단 위치는 추정해서 고정하지 않는다.
4. 수정 동선·충돌·문 개폐 검사, 전체 검사·타입 검사·빌드, PC와 휴대폰 크기 화면에서 실제 조작을 확인한다.

## 주석 사진에 따른 수정

- 기존 ‘텃밭’ 두 구획은 필로티 주차장으로 바꾼다. 동쪽 가장자리 북쪽 진입 구획의 벽도 열되, 남쪽 계단은 유지한다.
- 주차장 네 기둥과 복도 쪽 창벽은 화면과 이동 충돌에 함께 반영한다. 도서 반납함·보안관실·전면 화단도 통과하지 않도록 한다.
- 텃밭은 건물 밖 동편, 분리수거장은 매점 옆 바깥으로 옮긴다. 동편 전체 보기에서 시설 이름이 보이도록 한다. 사진의 좌우 관계가 기준이며 실제 거리는 측정하지 않았다.
- 중앙로비와 동편출입구 양쪽으로 실내·외를 오갈 수 있다. 촬영하지 않은 방의 세부 소품과 운동장 계단 위치는 추가 자료가 필요하다.

## 표현 범위

영상의 이동 시간은 길이 측정값이 아니다. 정확한 폭·거리·창 개수·내부 가구 배치를 영상만으로 확정하지 않는다. 복도에서 보이는 큰 특징을 옮기되, 촬영되지 않은 교실·특별실 내부는 후속 자료로 보완한다. 유리벽은 캐릭터가 가려지지 않도록 투명도와 벽 높이를 탐방 화면에 맞게 조절한다. 외부 시설은 전체 보기의 위치 안내이며 이번 변경으로 운동장 전체 자유 이동을 추가하지 않는다.
