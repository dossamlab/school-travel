# 학교 캐릭터 만들기 — Meshy AI와 Blender

방문자가 조종하는 학생은 학교 교복을 입고 있습니다. 교문의 교장선생님, 교장실·교무실의 선생님, 학교보안관, 숙직실 경비원도 3D 캐릭터로 서 있습니다. 이 안내서는 [Meshy](https://www.meshy.ai/)로 우리 학교 캐릭터를 만들고 Blender로 사이트에 맞게 다듬는 순서입니다.

| 캐릭터 | 사이트가 읽는 파일 | 만드는 스크립트 | 움직임 |
| --- | --- | --- | --- |
| 학생(플레이어) | `public/school-player-meshy.glb` | `assets/prepare_player.py` 또는 `assets/prepare_school_meshy.py` | 서기·걷기·앉기·운동 |
| 교직원 4명 | `public/school-residents.glb` | `assets/prepare_school_residents_meshy.py` | 서 있거나 앉은 자세(고정) |

## 먼저 지킬 것

- **학생 사진을 Meshy에 올리지 않습니다.** 교복은 글로 설명하거나, 사람이 나오지 않은 교복 사진(옷걸이·마네킹)을 씁니다. 얼굴·명찰·학교 이름이 보이면 잘라 냅니다.
- 실제 선생님을 닮게 만들려면 **그 선생님의 동의를 먼저** 받습니다. 사진을 외부 서비스에 올리는 것까지 동의 범위에 넣습니다. 닮지 않은 일반 교직원으로 만드는 편이 가장 안전합니다.
- 원본 사진은 `references/`에만 두고 저장소에 올리지 않습니다.
- 특정 영화·게임 캐릭터를 그대로 따라 만들지 않습니다.
- Meshy 무료 요금제로 만든 모형은 **CC BY 4.0**(출처 표시하면 상업적 이용도 가능)입니다. 유료 요금제(Pro 이상)는 "개인 및 고객 소유" 비공개 라이선스라 만든 사람이 공개 조건을 정합니다(2026-10 Meshy 가격 페이지 기준). 에셋을 열고 아래 정보 칸의 **라이선스**를 확인해 `ASSET_CREDITS.md`에 적습니다.
- 생성할 때마다 크레딧이 듭니다. 생성 전에 화면에 표시된 소모 크레딧을 확인합니다.

## 1. 교복 정리하기

`references/교복.md`에 교복을 글로 적습니다. AI에게 사진을 보여 주고 받아 적게 해도 됩니다.

```text
재킷: 버건디색, 베이지 파이핑(테두리), 단추 2개
셔츠: 흰색 / 넥타이: 남색·베이지 사선 줄무늬
조끼: 회베이지 니트 / 바지: 베이지 긴바지 / 신발: 검은 구두
```

## 2. Meshy에서 학생 만들기

1. Meshy에서 **Text to 3D**(글로 만들기)를 엽니다. 교복 사진(사람 없는 것)이 있으면 **Image to 3D**도 됩니다.
2. 아래 요청문의 `<교복 설명>`을 영어로 바꿔 넣습니다. 청학고 주인공과 같은 포근한 그림체가 나오도록 비율과 자세를 정해 둔 요청문입니다.

```text
A single original cute high school student for a cozy 3D school tour game, full body in a neutral A-pose for animation rigging, arms angled down 40 degrees away from the torso, hands empty and separate, feet apart on the ground. Chibi proportions with a large round head about 40 percent of total height, short stocky torso, short thick limbs, rounded hands, simple large dark eyes and a small friendly smile, short neat hair, warm peach skin. Wearing the school uniform: <교복 설명>. Premium cozy clay-toy game art, smooth rounded sculpt, broad clean color shapes, matte surfaces. No name tag, no school logo, no text, no props, no bag, no pedestal, no scenery.
```

3. 마음에 드는 모형을 고르고 **Texture**(색칠) 단계에서 교복 색을 다시 한번 적습니다.
4. **Rigging(관절)** 에서 사람형(humanoid)을 고르고 관절 위치를 확인한 뒤, **Animation**에서 **Walking(걷기)** 을 추가합니다.
5. **GLB**로 내려받습니다. 관절과 걷기 동작이 들어 있는 파일이어야 합니다.
6. 파일을 `assets/school-player-rig-source.glb`로 저장합니다. 원본은 고치지 않고 보존합니다.

## 3. Blender로 사이트용 학생 만들기

### 방법 A — Meshy 관절을 그대로 쓰기 (권장)

Meshy가 넣어 준 관절과 걷기 동작을 그대로 쓰고, 면 수·이미지 크기·서 있는 자세만 정리합니다. 청학고의 첫 주인공이 이 방법으로 만들어졌습니다.

```bash
blender --background --python-exit-code 1 --python assets/prepare_player.py -- assets/school-player-rig-source.glb public/school-player-meshy.glb
```

Blender가 명령 검색 경로에 없으면 `blender`를 설치 경로로 바꿉니다. Windows의 Git Bash 예: `"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe"`.

이 스크립트는 다음을 합니다.

- 관절 이름을 사이트의 약속(`playerHips`, `playerArmL/R`, `playerLegL/R`, `playerFootL/R`)으로 바꿉니다.
- 머리를 키우고 몸을 줄여 포근한 비율로 다듬습니다. 표면과 관절을 같이 움직이므로 걷기가 어긋나지 않습니다.
- 걷기(`Walk`)를 새 비율에 맞게 옮기고, 멈췄을 때의 서기(`Idle`)를 더합니다.
- 삼각형 24,000개, 색 이미지 1024px 이내로 줄입니다. 사이트는 키를 1.70m로 맞춰 보여 줍니다(`src/school-plan-data.ts`의 `schoolPlayerHeight`).

마지막 줄의 `PLAYER_MOBILE {...}`에서 크기·삼각형 수·관절 수를 확인합니다.

### 방법 B — 관절 없는 모형에 관절 심기 (청학고 교복 주인공 방식)

Meshy에서 관절을 넣지 않은 모형(자세가 기울어진 모형 포함)을 쓸 때입니다. `assets/prepare_school_meshy.py`가 어깨·팔꿈치·무릎 같은 관절 위치를 표(`bones`)로 직접 적고, 기존 걷기 동작(`assets/player.glb`)을 옮겨 붙입니다. 표의 숫자는 청학고 모형에 맞춰 잰 값이라 **새 모형마다 다시 재야** 합니다.

> **AI 요청문**
>
> `assets/school-player-meshy-source.glb`를 새 학생 모형으로 바꿨어. Blender로 정면·옆면을 렌더링해서 키 1.7m 기준으로 관절 위치를 다시 재고 `assets/prepare_school_meshy.py`의 `bones` 표를 고쳐 줘. 청학고 재킷 색을 바꾸는 색 보정 부분은 우리 교복에 필요 없으면 빼. 다 되면 스크립트를 실행하고 `npm test`의 `school-player-meshy.glb` 검사를 통과시켜 줘.

### 확인

```bash
npm test
```

`tests/player.test.ts`가 학생의 키, 발 접지, 걷기 중 한쪽 발이 바닥을 딛는지 확인합니다. 그다음 `npm run dev`로 실제 학교 화면에서 걷기·문 통과·의자에 앉기·운동기구·응원 자세를 봅니다.

새 모형을 넣으면 **청학고 교복 모형에 맞춘 검사 3개가 실패하는 것이 보통**입니다. 방법 A로 다른 Meshy 모형을 넣어 시험했을 때도 그랬습니다(2026-10-22).

| 실패하는 검사 | 이유 | 할 일 |
| --- | --- | --- |
| `hips must retain the selected character's proportions` | 엉덩이 높이 비율 범위가 청학고 모형 값(0.25~0.30) | 새 모형의 비율로 범위를 바꿈 |
| `school character keeps its jacket intact through every interaction pose` | 앉기·운동·응원 자세에서 옷 표면이 크게 늘어나는지 검사 | **실제 화면에서 팔·옷이 찢어지듯 늘어나는지 먼저 봅니다.** 늘어나면 관절 무게를 고치고, 괜찮으면 기준을 조정 |
| `school-player-meshy retains a skinned, self-contained mobile character` | 표면 이름 `SchoolUniform`을 찾음 | 방법 A의 표면 이름은 `ExplorerSurface`. 검사나 스크립트의 이름을 맞춤 |

> **AI 요청문**
>
> 새 학생 모형을 넣었더니 `npm test`의 학생 검사 3개가 실패해. 먼저 개발 서버에서 걷기·앉기·운동·응원 자세를 화면으로 확인하고, 옷이나 팔이 늘어나는 문제가 있으면 모형을 고쳐 줘. 문제가 없을 때만 청학고 모형에 맞춘 숫자와 이름을 새 모형에 맞게 바꾸고, 검사가 확인하는 내용 자체는 유지해.

## 4. 교직원 캐릭터

교직원은 걷지 않고 정해진 자리에 서 있거나 앉아 있으므로 관절이 필요 없습니다.

1. Meshy에서 같은 방법으로 만들되, 아래 요청문에 역할별 옷차림을 넣습니다.

```text
Cozy stylized 3D school game character, full body, large rounded head about 40 percent of total height, compact adult body, short limbs, rounded hands and shoes, warm peach skin, soft matte materials, sturdy eyeglass frames visible at small screen size, gentle approachable expression. Neutral symmetrical relaxed A pose, arms slightly separated from the torso, feet separated. Wearing <옷차림>. One character only, no props, no furniture, no pedestal, no text, no background.
```

2. 내려받은 GLB를 아래 이름으로 `assets/`에 둡니다. 스크립트가 이 이름을 읽습니다.

| 역할 | 파일 | 사이트에서 서는 곳 |
| --- | --- | --- |
| 교장선생님 | `assets/principal-meshy-source.glb` | 교문 앞, 교장실 |
| 교감선생님 | `assets/vice-principal-meshy-source.glb` | 2층 교무실 |
| 학교보안관 | `assets/school-marshal-meshy-source.glb` | 교문 옆 보안관실 |
| 숙직실 경비원(앉은 자세) | `assets/night-guard-meshy-source.glb` | 숙직실 |

3. Blender로 모형을 만듭니다.

```bash
blender --background --python-exit-code 1 --python assets/prepare_school_residents_meshy.py
```

스크립트는 키를 1.70m로 맞추고, 학생과 같은 큰 머리 비율이 되도록 목 위를 키웁니다. 목 높이는 모형마다 다릅니다(`neck` 값). 머리가 어색하면 AI에게 다시 재게 합니다.

> **AI 요청문**
>
> 교직원 4명의 Meshy 모형을 바꿨어. 각 모형의 목 높이를 Blender로 재서 `assets/prepare_school_residents_meshy.py`의 `neck` 값을 고치고 스크립트를 실행해 줘. 교감선생님은 우리 학교에서 1층 교무실에 계시니 `src/school-principal.ts`와 `src/school-upper-floors.ts`의 위치도 옮겨 줘.

교직원이 서는 위치는 `src/school-layout.ts`의 `schoolResidents`(1층과 교문), 인사하는 대상과 문구는 `src/school-principal.ts`에 있습니다. 교장선생님의 인사말은 [시트](시트-연결.md)에서 고칠 수 있습니다.

## 5. 출처 남기기

`ASSET_CREDITS.md`에 캐릭터마다 다음을 적습니다.

- 만든 사람(계정), 만든 날, Meshy 모형 종류
- 내려받을 때 표시된 라이선스(무료 요금제는 CC BY 4.0)
- 원본 파일 이름과 Blender로 바꾼 내용
- 실제 인물을 참고했다면 동의를 받았다는 사실(이름·사진은 적지 않음)

사이트의 도움말 아래 출처 문구는 `src/school-config.ts`의 `about.credits`에서 바꿉니다.
