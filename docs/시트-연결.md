# 시트 연결 — 방명록·교장선생님 인사말·공간 안내

사이트를 다시 배포하지 않고 선생님이 Google 스프레드시트에서 직접 고치는 세 가지가 있습니다.

| 기능 | 시트 탭 | 사이트에서 보이는 곳 |
| --- | --- | --- |
| 방명록 | `방명록` | 메뉴의 방명록. 선생님이 승인한 글만 공개 |
| 교장선생님 인사말 | `학교 안내` | 교문 앞·교장실의 교장선생님에게 다가가 인사 |
| 공간 안내 | `공간 안내` | 특별실 문을 열 때, 목적지 목록의 설명 버튼 |

시트는 **비공개로 둡니다.** 사이트는 Google Apps Script 웹앱에서 공개해도 되는 글만 JSON으로 받아 직접 그립니다. 방문자의 Google 로그인 쿠키를 보내지 않고, 시트 화면을 사이트에 끼워 넣지도 않습니다.

시트를 연결하지 않아도 사이트는 동작합니다. `src/school-config.ts`의 `dataUrl`이 비어 있으면 세 기능은 "아직 학교 안내 시트를 연결하지 않았어요"라고만 보여 줍니다.

## 처음 한 번 — 시트 견본 사본 만들기

탭·체크박스·안내 메모와 Apps Script가 모두 준비된 **시트 견본**을 복사해서 씁니다. 사본은 선생님의 Google Drive에 생기며, 견본이나 청학고 시트와는 이어지지 않습니다.

### 1. 사본 만들기

1. 학교 업무용 Google 계정으로 로그인한 뒤 **[학교 여행 · 시트 견본 사본 만들기](https://docs.google.com/spreadsheets/d/1e1tEFGbaoJ7IfpkZejp4QVnJqZTCuUJjpEWcnYkBNfQ/copy)** 를 엽니다.
2. "첨부된 Apps Script 파일 및 기능도 복사됩니다"를 확인하고 **사본 만들기**를 누릅니다.
3. 사본 이름을 "○○ 여행 · 시트"처럼 바꿉니다.

### 2. 우리 학교 내용으로 바꾸기

- `학교 안내` 탭 2행의 환영 인사를 우리 학교 문구로 고칩니다. 3~5행의 소개 항목은 쓰고 싶은 것만 채워 D열을 체크합니다.
- `공간 안내` 탭의 장소 목록은 청학고 견본 배치 그대로입니다. 배치를 바꿨다면 아래 명령의 출력으로 바꿉니다. 먼저 A2부터 아래의 A~C열 내용을 지우고, A2 칸을 누른 뒤 붙여 넣으면 장소 ID·층·장소명이 칸마다 나뉘어 들어갑니다.

```bash
npm run -s room-rows -- --tsv
```

배치를 바꿀 때마다 장소 ID가 달라질 수 있으므로, **배치를 다 바꾼 뒤** 붙여 넣는 것이 좋습니다.

### 3. 웹앱으로 배포하기

1. 사본에서 **확장 프로그램 → Apps Script**를 엽니다. 「학교 여행 · 방명록」 프로젝트가 열립니다.
2. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
3. 유형은 **웹 앱**, 다음 사용자 인증 정보로 실행은 **나**, 액세스 권한이 있는 사용자는 **모든 사용자**로 고릅니다. 방문자가 로그인하지 않고 공개 글을 읽고 방명록을 남기기 위한 설정입니다. 시트 자체가 공개되지는 않습니다.
4. **배포**를 누르면 권한 확인 창이 뜹니다. 학교 계정을 고르고 허용합니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 선생님 계정의 스크립트라서 나오는 경고이며, 스크립트는 이 사본 시트만 읽고 씁니다.
5. 나온 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 복사해 `src/school-config.ts`의 `dataUrl`에 붙여 넣고 사이트를 다시 배포합니다.

> 견본 없이 직접 만들고 싶다면: 새 Apps Script 프로젝트에 `assets/school-guestbook.gs`를 붙여 넣고, `setupGuestbook_`·`setupSchoolGuide_`·`setupRoomGuide_`를 차례로 부르는 임시 함수를 실행하면 새 시트와 세 탭이 만들어집니다(이름이 `_`로 끝나는 함수는 실행 목록에 나오지 않습니다). 이때 시트 주소는 스크립트 속성 `SHEET_ID`에 저장됩니다.

저장소의 `assets/school-guestbook.gs`가 바뀌어 Apps Script 코드를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누릅니다. 이렇게 하면 주소가 그대로입니다. "새 배포"를 다시 만들면 주소가 바뀌므로 `dataUrl`도 바꿔야 합니다.

## 날마다 쓰기

### 방명록

- 방문자의 글은 `방명록` 탭에 쌓입니다. 저장하는 것은 작성 시각, 닉네임(선택), 글, 공개 승인뿐입니다. 실명·학번·연락처는 받지 않습니다.
- **D열 공개 승인**을 체크한 글만 사이트에 나옵니다. 체크를 풀면 다시 숨겨집니다. 최신 승인 글 30개를 보여 줍니다.
- 이름이나 연락처가 적힌 글은 승인하기 전에 그 부분을 지우거나 승인하지 않습니다.
- 글은 2~300자, 닉네임은 20자까지입니다. 같은 브라우저는 1분에 한 번, 하루 전체 300건, 누적 10,000건까지 받습니다. 계정 인증이나 완벽한 스팸 차단을 대신하지는 않습니다.

### 교장선생님 인사말 — `학교 안내` 탭

| 열 | 넣을 내용 |
| --- | --- |
| A · 종류 | 첫 인사말은 `환영인사`, 고를 수 있는 이야기는 `소개` |
| B · 선택지 제목 | `학교 연혁`, `학교의 자랑`처럼 방문자가 누를 버튼 이름 |
| C · 소개 문구 | 실제로 보여 줄 글. 셀 안 줄바꿈은 `Ctrl+Enter`(Mac `⌘+Enter`) |
| D · 공개 | 체크한 행만 사이트에 나옴 |

- 줄 전체가 `---`인 줄로 글을 나누면 대화창에서 `이전`·`다음`으로 넘기는 페이지가 됩니다. 한 페이지는 7~8줄 이내가 읽기 좋습니다.
- 공개된 `환영인사`가 여러 개면 맨 위 것을 씁니다. 없으면 기본 환영 문구가 나옵니다.
- 저장한 뒤 사이트에서 대화를 다시 열거나 `다시 불러오기`를 누르면 바로 바뀝니다. 다시 배포할 필요가 없습니다.
- 학생·학부모·교직원의 개인정보는 넣지 않습니다.

### 공간 안내 — `공간 안내` 탭

| 열 | 용도 |
| --- | --- |
| A · 장소 ID | 사이트와 연결하는 고유번호. **고치지 않습니다** |
| B · 층 / C · 장소명 | 어느 장소인지 확인용 |
| D · 소개 문구 | 방문자에게 보여 줄 글. 줄바꿈 가능 |
| E · 공개 | 체크한 문구만 공개 |

문구가 비었거나 공개를 체크하지 않은 장소는 "아직 입력된 내용이 없습니다"로 나옵니다. 사이트에 장소를 새로 추가했다면 `npm run room-rows`로 새 장소 ID를 확인해 행을 추가합니다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| "연결이 원활하지 않아요" | `dataUrl`이 `/exec`로 끝나는지, 웹앱 액세스가 "모든 사용자"인지 |
| 고친 Apps Script가 반영되지 않음 | "배포 관리 → 새 버전"으로 다시 배포했는지 |
| 방명록 저장이 안 됨 | `방명록` 탭 이름을 바꾸지 않았는지, 하루 접수 한도(300건)를 넘지 않았는지 |
| 공간 안내가 모두 비어 있음 | E열을 체크했는지, A열 장소 ID가 `npm run room-rows`와 같은지 |

무료 Apps Script 실행 한도 안에서 동작합니다. 접속이 몰리면 Google 서비스 한도 때문에 잠시 제한될 수 있습니다.
