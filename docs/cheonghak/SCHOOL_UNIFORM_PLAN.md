# 청학고 교복 주인공 제작

사용자가 제공한 사진의 버건디 재킷·베이지 파이핑, 흰 셔츠, 사선 줄무늬 넥타이, 회베이지 니트 조끼, 베이지 긴바지를 기존 주인공 비율에 맞춘다. 얼굴·체형·명찰의 개인정보는 복제하지 않고 원본 사진을 저장소나 외부 서비스로 전송하지 않는다.

- 기존 `public/player.glb`를 읽어 머리·손과 관절·Idle/Walk를 유지하고, 학교용 의복을 Blender에서 만든다. 출력은 별도 `public/school-player.glb`이다.
- 후드·가방·반바지의 단순 재색칠 대신 재킷·칼라·라펠·주머니·바지를 입체 구성한다. 지나치게 작은 디테일은 줄이고 기존 포근한 비율을 유지한다.
- `assets/build_school_player.py`에 재현 가능한 제작 과정을 남기고 학교 장면만 새 모형을 사용한다. 새 유료 생성이나 서비스 설치는 하지 않는다.
- 기존 걷기 검사에 학교 주인공을 포함해 접지·관절·비율을 검사하고, 새 모형의 내장 이미지·크기·삼각형 수를 확인한다.
- 정면·측후면과 실제 학교 화면에서 옷의 겹침·걷기를 확인하고 타입 검사·전체 검사·빌드 후 로컬 견본을 갱신한다.

## Meshy 교복 모형으로 교체

사용자가 추가한 `assets/school-player-meshy-source.glb`는 관절·동작이 없는 약 10.4MB의 모형이며 한쪽 다리를 든 자세다. 얼굴·교복·원본 이미지는 유지하고, `assets/prepare_school_meshy.py`가 별도의 `public/school-player-meshy.glb`를 만든다. 이전 모형과 제작 스크립트는 보존한다.

- 원본 모형에서 어깨·팔꿈치·손목·골반·무릎·발목 위치를 잡아 18개 관절과 표면의 관절 영향도를 구성한다.
- 원본의 들린 다리를 중립 자세로 펴고 기존 `player.glb`의 Walk 동작을 새 관절 축으로 변환한다. 정지 시에는 Idle 동작으로 돌아간다.
- 전체 키는 1.70m, 모형은 25,000삼각형·2MiB 이내로 유지한다. 교복과 얼굴의 표면 이미지를 내장하고 외부 유료 서비스는 호출하지 않는다.
- 원본과 후보를 렌더로 비교하고, 기본 자세·걷기·발 접지·문 통과·실제 학교 화면을 검증한 뒤 학교 장면의 파일 경로만 교체한다.

### 2026-10-15 표면 색상 보정

- 축소 화면에서 UV 조각의 이웃 색상이 섞여 머리카락에 밝은 점·선이 생기는 현상을 확인했다. 게임용 색상 이미지를 2048×2048로 유지하고 이 모형만 축소 밉맵을 사용하지 않도록 했다. 경계 결함을 강조하던 노멀 이미지는 제거한다.
- 자주색 재킷 픽셀만 따뜻한 버건디 방향으로 보정한다. 피부·얼굴·니트·바지·교복의 실제 베이지 파이핑은 유지한다. Blender에서 보정한 게임용 결과는 1,343,220바이트·22,000삼각형이며, 18관절·Idle/Walk·키 1.70m는 동일하다.
- 원본 GLB는 수정하지 않는다. 확대·실제 게임 크기 화면에서 확인하며, 촘촘한 무늬의 축소 필터 변경은 학교 주인공에만 적용한다.

### 2026-10-15 피부색 추가 보정

- 얼굴·목·손에 해당하는 관절 영역과 표면 이미지의 피부색을 함께 골라 따뜻한 복숭아빛으로 보정한다. 눈·머리카락·셔츠·니트·바지는 보정 대상에서 제외하고 원래 명암을 유지한다.
- 원본 GLB는 보존하며, 게임용 결과는 1,391,628바이트·22,000삼각형이다. 학교 장면의 실제 조명 아래에서 얼굴과 손의 색을 확대해 확인했다.
